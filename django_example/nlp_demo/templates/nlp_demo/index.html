Sobre a Biblioteca

Esta página demonstra a classe preprocessing_ptBR do pacote nlp_portugues.py, criada durante pesquisa de doutorado na UFMG. As listas incluem 1.731 stop-words, 6.627 adjetivos e 260.524 verbos/conjugações em português.
Método Descrição
clear_text(texto) Remove acentos, caracteres especiais e números; converte para minúsculas
plural2_singular(tokens) Converte lista de tokens do plural para singular
proc_text(text, verbs, adjectives, plural, string) Pré-processamento completo: remove stop-words e, opcionalmente, verbos e adjetivos

Como Executar

Execute os comandos abaixo a partir da raiz do repositório:
  1. Instalar dependências: pip install -r django_example/requirements.txt
  2. Entrar na pasta: cd django_example
  3. Iniciar o servidor: python manage.py runserver
  4. Abrir no navegador: http://127.0.0.1:8000/
